Zerodha Kite Connect

checking…
Powers your signal evaluations, the shared F&O Scanner (when you're the one who runs a scan), and live order placement. Kite's access token expires every day -- you'll need to click "Log in to Kite" again each trading morning; that's a Zerodha platform limitation.

Upstox

checking…
Powers your signal evaluations, the shared F&O Scanner, and live order placement -- same role as Kite above, for accounts on Upstox instead. Upstox's access token expires at 3:30am every day -- you'll need to click "Log in to Upstox" again each trading morning.

Dhan

checking…
Powers your signal evaluations, the shared F&O Scanner, and live order placement -- same role as Kite/Upstox above. Dhan has no "log in" button here: generate a Client ID and a 24-hour access token yourself from web.dhan.co → My Profile → Access DhanHQ APIs, then paste both below. You'll need to re-generate and re-paste a fresh token every 24 hours.

Other brokers

Credentials are stored locally. These don't have a working order-placement adapter yet -- only Kite, Upstox, and Dhan (above) are fully wired up.
